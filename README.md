# Ultra-Luxury 3D Interactive Portfolio

Apple компаниясының ресми таныстырылымдары мен Awwwards жеңімпаздарының стилінде жасалған келесі буын 3D интерактивті портфолио веб-сайты.

## Негізгі ерекшеліктер (Features)

1. **Дизайн жүйесі & Apple Keynote стилі**:
   - Deep Dark OLED UI (`#000000`, `#030712`), сұйық шыны (liquid glassmorphism) әсерлері және тегіс градиенттер.
   - San Francisco / Inter типографикалық иерархиясы.
2. **3D Tilt эффектілі жеке визитка (Personal Card)**:
   - Басты беттегі курсордың қозғалысына сай нақты уақытта 3D кеңістігінде қисаятын (60 FPS tilt physics), динамикалық жылтыр жарық (specular sheen) әсері бар интерактивті визитка.
3. **Кинематографиялық скролл және анимациялар**:
   - Скролл жасағанда элементтердің жұмсақ жарқырап ашылуы (cinematic glow reveals).
   - Жобалар галереясы: карточкаға жақындағанда артынан жұмсақ неон сәулесі (cursor-following ambient light) шығып тұрады.
4. **Интерактивті модаль терезе (Contact Modal)**:
   - "Байланысу" батырмасымен тегіс шығатын сәнді байланыс формасы.
5. **Қос тілді қолдау (Bilingual Support)**:
   - Qazaq (Latin әліпбиі) және English тілдері арасында лезде ауысу.

## Жобаны іске қосу (Local Development)

```bash
# Python көмегімен жергілікті серверді қосу:
python3 -m http.server 8000

# немесе Node.js көмегімен:
npx serve -l 8000 .
```
Браузерде ашыңыз: `http://localhost:8000`
